# dhfolio.github.io

Personal academic site, served at https://dhfolio.github.io.

For now it is a static, read-only mirror of the previous site: the frontend
reads JSON files under `data/public/` instead of calling an API.

## Commands

Node 20 or newer, no dependencies to install.

    node tools/sync-public.mjs   # pull public data and media from the previous site
    node tools/build-site.mjs    # assemble the deployable site in _site/
    node tools/dev-server.mjs    # preview locally
    node --test "tools/test/*.test.mjs"

## Deploys

`.github/workflows/pages.yml` builds and deploys to GitHub Pages on every push
to `main`. Every 6 hours, and on manual dispatch, it runs the sync first and
commits any changes before deploying. If the sync fails, nothing is deployed
and the last good version stays live.

`data/public/` and `media/` are generated by the sync. Do not edit them by
hand; the next sync overwrites them.
